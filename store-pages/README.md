# ACC Coach: public pages

Static pages for the Microsoft Store listing of ACC Coach (a sim-racing team's telemetry app):

- `index.html`: what the app is (the listing's "Website" link)
- `privacy/index.html`: the privacy policy (the listing's "Privacy policy URL")

Published with GitHub Pages. Plain HTML and CSS, no outside fonts or scripts, so they load from
anywhere. They are copied from the `store-pages/` folder of the app's own repository, where the
privacy policy is kept in line with the team site's `/privacy` page.
